# เว็บดูอย่างเดียวสำหรับครู (Google Apps Script)

เว็บนี้อ่านข้อมูลจากไฟล์ชีต "สรุปเนื้อหารายครู เทอม 1-2 ปี 2569" ครูเปิดลิงก์ดูได้เลยโดยไม่ต้องล็อกอิน
แต่แก้ข้อมูลไม่ได้ หน้าเว็บอัปเดตเองทุก 30 วินาที

## ติดตั้ง (ทำครั้งเดียว ใช้คอมพิวเตอร์ หรือ Safari บน iPad ที่เลือก "ขอเว็บไซต์เดสก์ท็อป")

1. เปิดไฟล์ชีต → เมนู **ส่วนขยาย (Extensions) → Apps Script**
2. ลบโค้ดเดิมในไฟล์ `Code.gs` ให้หมด แล้ววางโค้ดจาก `term2-planner/apps-script/Code.gs`
3. กดบันทึก (ไอคอนแผ่นดิสก์)
4. กด **ทำให้ใช้งานได้ (Deploy) → การทำให้ใช้งานได้รายการใหม่ (New deployment)**
   - กดไอคอนเฟือง แล้วเลือก **เว็บแอป (Web app)**
   - ช่อง **ดำเนินการในฐานะ (Execute as):** เลือก **ฉัน (Me)**
   - ช่อง **ผู้ที่มีสิทธิ์เข้าถึง (Who has access):** เลือก **ทุกคน (Anyone)**
   - กด **ทำให้ใช้งานได้ (Deploy)**
5. Google จะขอสิทธิ์ ให้กด **ให้สิทธิ์เข้าถึง** แล้วเลือกบัญชีของคุณ
   ถ้าเจอหน้า "Google ยังไม่ได้ยืนยันแอปนี้" ให้กด **ขั้นสูง → ไปที่ … (ไม่ปลอดภัย)** แล้วกด **อนุญาต**
   หน้านี้ขึ้นเพราะเป็นสคริปต์ของคุณเอง สคริปต์ใช้สิทธิ์แค่อ่านไฟล์ชีตนี้และดึงหน้าเว็บจาก GitHub
6. คัดลอก **URL ของเว็บแอป** ที่ลงท้ายด้วย `/exec` ไปส่งให้ครู

## อัปเดต
- **หน้าเว็บ:** โหลดจาก GitHub (branch `main`) และเก็บแคชไว้ 5 นาที เมื่อหน้าเว็บมีการแก้ไข ไม่ต้องติดตั้งใหม่
- **ไฟล์ `Code.gs`:** ถ้ามีการแก้ ให้วางโค้ดใหม่ แล้วกด **Deploy → จัดการการทำให้ใช้งานได้ → แก้ไข → เวอร์ชันใหม่** URL เดิมยังใช้ได้
